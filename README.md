# SafeRoute Damascus

A prototype for organizing school minibus pickups in Damascus. Schools set up routes, parents register their kids and follow pickup progress, and drivers get a clear stop order for the morning.

The data is mock data for now (schools, neighbourhoods, routes and stops), but the screens show how the full system would work.

**Built with** Next.js 14, React, TypeScript, Tailwind CSS, Leaflet maps, Recharts

**Pages**
- Home page with a live route map and quick stats
- Parent registration form
- Driver view with stop order, pickup status and delays
- School dashboard with route coverage and delay charts

**Run it**
```bash
npm install
npm run dev   # http://localhost:3007
```
